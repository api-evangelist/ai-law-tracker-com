AI Law Tracker is an independent knowledge hub that aggregates and explains AI laws, regulations, and policy developments across U.S. states, the EU, and other jurisdictions. It provides plain‑English explanations and a free, versioned JSON API and MCP server for developers to integrate regulatory intelligence into their products.

**Areas:** Company · AI · Law · Regulatory · Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AI Law Tracker: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
